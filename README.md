# NOIRE — Fashion & Clothing Store

A responsive luxury fashion storefront built with React + Vite.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown in the terminal.

## Production build
```bash
npm run build
npm run preview
```

## Deploy on Vercel
- Push the entire project folder to a GitHub repository.
- In Vercel, choose **Add New → Project** and import the repository.
- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Click **Deploy**.

The storefront uses demo product data and a demo checkout interaction. No real payments or orders are processed.
